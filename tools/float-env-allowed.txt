# The public functions that need not enter the library's floating-point
# environment (tools/check_float_env.py): each listed under the reason,
# true of every name under it, that it computes no float.

makes an easing from integers, pointers and constants, computing no float:
    mtwnMakeLinearEasing
    mtwnMakeHostEasing
    mtwnMakeStepsEasing

makes a default from constants, computing no float:
    mtwnDefaultTiming
    mtwnDefaultStagger

reports a stored count, flag, identity, name or the version, computing no float:
    mtwnGetVersion
    mtwnGetResultName
    mtwnContext_GetEventCount
    mtwnContext_GetDroppedEventCount
    mtwnContext_GetMisuse
    mtwnContext_GetSerialAdvanceCount
    mtwnContext_GetMemoryBytes
    mtwnContext_IsReducedMotionEnabled
    mtwnContext_GetPlayingOnCount
    mtwnTarget_IsValid
    mtwnPlayer_IsValid
    mtwnClip_IsValid

frees the context's memory through the host's allocator, computing no float:
    mtwnDestroyContext
